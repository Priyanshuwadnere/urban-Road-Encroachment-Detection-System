## 🚀 How to Open and Compile in Overleaf (Recommended)

### Method A: One-Click ZIP Upload (Fastest)
1. Go to [Overleaf](https://www.overleaf.com) and log in.
2. Click **"New Project"** -> **"Upload Project"**.
3. Select or drag-and-drop **`IEEE_Paper_Urban_Road_Encroachment_Detection.zip`**.
4. In Overleaf, set the main document to `IEEE_Research_Paper_Urban_Road_Encroachment.tex` and click **"Recompile"**.
5. Your publication-ready IEEE PDF will be compiled and ready to download!

### Method B: Copy & Paste
1. Create a blank project in Overleaf.
2. Open `IEEE_Research_Paper_Urban_Road_Encroachment.tex` in any text editor (Notepad, VS Code).
3. Copy all text and paste it into `main.tex` in Overleaf.
4. Click **"Recompile"**.
