Spatial Analysis Workflow
OUTSIDE_PRIVATE = DETECTED_STRUCTURE − LEGAL_PROPERTY_BOUNDARY
POTENTIAL_ENCROACHMENT = OUTSIDE_PRIVATE ∩ GOVERNMENT_ROAD_ROW

The framework formally decouples Computer Vision Physical Segmentation from Cadastral Vector Set Algebra. An awning, ramp, or shed is a lawful architectural feature when constructed within a private property setback, but becomes an illegal statutory violation when projecting across the cadastral property line into the municipal Road Right-of-Way. The system identifies physical boundaries using instance segmentation and determines compliance downstream via exact geometric set operations.

System Architecture & Processing Pipeline
1. DRONE REMOTE SENSING → Aerial nadir photogrammetric survey frame (1024 × 723 px, GSD ≈ 5 cm/px)
2. INSTANCE SEGMENTATION → Edge-optimized YOLOv8n-seg predicts physical structure polygons (S_px)
3. COORDINATE REGISTRATION → Inverse affine homography transformation A ∈ ℜ³⊃³ maps contours to metric GIS frame
4. SPATIAL SET ALGEBRA → OUTSIDE_PRIVATE = S \ P and POTENTIAL_ENCROACHMENT = O ∩ R_ROW
5. MUNICIPAL ATTRIBUTION → Centerline projection computes Station (0+0XX.X), Lateral Depth (m), Frontage (m)
6. DECISION SUPPORT & REPORTING → Generates audit-ready Municipal Encroachment Notices & Technical Dossiers
